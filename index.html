Coreness

Мультитенантная платформа для production-ready AI-агентов и чат-ботов. Один экземпляр — множество изолированных ботов, полная документация, развёртывание за минуты.

  • • Декларативная логика в YAML — сложные сценарии без кода, изоляция данных через RLS
  • • LLM и RAG: OpenAI, Anthropic, Google, DeepSeek; pgvector, рассылки и отчёты по расписанию
  • • Плагинная архитектура, фоновые задачи, готовый Master Bot для управления через Telegram
GitHub Документация

Coreness Flow

Десктопный агент, реагирующий на события: чат, webhook, cron. Сценарии в YAML, плагины с расширением UI по аналогии с VS Code, LLM и RAG полностью локально.

  • • Event-driven архитектура: триггеры → сценарии → плагины; async-действия без блокировки
  • • Плагины задают вкладки, сайдбар, настройки через contributes; BGE-M3 + Qdrant embedded
  • • Electron + React, Python backend; один пользователь, все данные под вашим контролем

Конфигурации и демо.

Coreness — Master Bot

Готовый бот для управления платформой через Telegram. Пример команд и конфигурации:

commands.yaml
start:
  description: "Start Master Bot"
  
  trigger:
    - event_type: "message"
      event_text: "/start"
    - event_type: "callback"
      callback_data: "start"

  step:
    - action: "execute_scenario"
      params:
        scenario: "default_check"
    
    - action: "send_message"
      params:
        text: |
          {_cache.translation.start}
        inline: "{_cache.translation.start_inline}"
config.yaml
i18n:
  available_languages:
    - en
    - ru
  default_language: en

environments:
  available:
    - test
    - prod
  default: prod

deployment:
  available_modes:
    - docker
    - native
  default: docker

Coreness

Установка
# Клонируйте репозиторий
git clone https://github.com/Vensus137/Coreness.git
cd Coreness

# Запустите Core Manager
python tools/core_manager/core_manager.py

# Выберите окружение и режим — утилита настроит всё

Coreness Flow

Из исходников (Python 3.11, Node.js, Windows)
# Клонируйте репозиторий
git clone https://github.com/Vensus137/Coreness-Flow.git
cd Coreness-Flow

# Установка и запуск с hot reload
pip install -r requirements.txt
cd frontend && npm install && cd ..
.\scripts\run-dev.ps1

Или скачайте установщик из блока Releases на GitHub.
