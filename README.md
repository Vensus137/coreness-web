# Coreness — the landing page

The source of [coreness.tech](https://coreness.tech): one page about **Coreness for DeepSeek Harness** — the panel that shows a profile as it really stands.

GitHub Pages serves the site from the `gh-pages` branch; this branch keeps the note and the licence.

`gh-pages` carries the page and nothing else:

- `index.html` — the page: the hero, the panel reproduced live, four rooms folded under an accordion, and the install;
- `demo/` — the panel the page mounts: one classic script and one stylesheet, no build step, no dependency;
- `favicon.svg` — the mark;
- `CNAME`, `robots.txt`, `sitemap.xml` — the domain and the crawlers.

Opening `index.html` from disk gives the page the site serves: no server, no build, and no request leaves the folder.
