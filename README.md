# Coreness Website

The source of the [coreness.tech](https://coreness.tech) landing — a small family of projects about governed agent work: what a project accepts, remembers and allows to be spent.

- **[Coreness Kit](https://github.com/Vensus137/Coreness-Kit)** — the rules of the work, written down and taken whole. A snapshot a project carries.
- **[Coreness for DeepSeek Harness](https://github.com/Vensus137/Coreness-DSH)** — the same idea, carried into an environment: a face, a memory and a brake for a profile.

GitHub Pages serves the site from the `gh-pages` branch.
